# mc-pi

Minecraft server running on a Raspberry Pi 5 (4 GB).

## Host

- Hostname: `mc-pi`
- OS: Raspberry Pi OS Lite 64-bit
- Architecture: ARM64 / aarch64
- Administration: SSH + Raspberry Pi Connect
- Storage: 128 GB microSD
- Network: Wi-Fi

## Goals

- Run a Minecraft server
- Start automatically after reboot
- Maintain automatic backups
- Keep configuration reproducible
- Monitor temperature, storage and memory
- Learn Linux and server administration along the way

## Security

Secrets, passwords and private SSH keys must never be committed to this repository.
